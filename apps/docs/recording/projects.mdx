---
title: Recording Projects
description: Organize recordings and links by assigning them to projects
---

Projects help you organize recordings and links into logical groups. Every recording link is assigned to a project, and the resulting recording inherits that assignment.

## Assigning a project

When you [create a recording link](/recording/requesting), select a **project** from the dropdown. If you don't choose one, the link is assigned to the workspace's **default project**.

<Steps>
  <Step title="Open the Create Link dialog">
    Click the [Create Link](https://dash.userplane.io/_/recordings?create_link=true) button in the top right corner.

    <Frame caption="Create Link button">
      <img src="/media/links/create-link/create-link-unfilled.png" />
    </Frame>

  </Step>
  <Step title="Select a project">
    Choose which project this recording belongs to from the **Project** dropdown.

    <Frame caption="Click show advanced options">
      <img src="/media/links/create-link/create-link.png" />
    </Frame>

    <Frame caption="Pick a project from the dropdown">
      <img src="/media/links/create-link/create-link-project-selection.png" />
    </Frame>

  </Step>
  <Step title="Create the link">
    Fill in the remaining details and click **Create**. The recording link inherits the selected project.
  </Step>
</Steps>

## How projects help

- **Filter recordings** — on the Recordings page, filter by project to see only the recordings that matter.

  <Frame caption="Project recordings view">
    <img src="/media/projects/view/view-recordings.png" />
  </Frame>

- **Filter links** — on the Links page, filter by project to find related links.

  <Frame caption="Filtering project recordings">
    <img src="/media/projects/view/view-recordings-filter.png" />
  </Frame>

- **Project views** — switch to a project-scoped view to see all recordings and links for a specific project.

  <Frame caption="Recording link in project view">
    <img src="/media/projects/view/view-recording-link.png" />
  </Frame>

- **Team organization** — use projects to separate recordings by product area, team, or customer segment.

## Managing projects

Projects are managed from [Workspace Settings > Projects](https://dash.userplane.io/_/settings?tab=general). See [Projects](/workspace/projects) for details on creating, editing, and deleting projects.

<Steps>
  <Step title="View your projects">
    Open [Workspace Settings > Projects](https://dash.userplane.io/_/settings?tab=general) to see all projects in your workspace.

    <Frame caption="Projects list">
      <img src="/media/projects/agent-browser-projects-list.png" />
    </Frame>

  </Step>
  <Step title="Create a new project">
    Click **Create Project** and enter a name for the project.

    <Frame caption="Create project dialog">
      <img src="/media/projects/agent-browser-create-project-dialog.png" />
    </Frame>

  </Step>
  <Step title="Edit a project">
    Click the menu on any project to edit its name or configure retention settings.

    <Frame caption="Project menu">
      <img src="/media/projects/agent-browser-project-menu.png" />

    <Frame caption="Edit project">

      <img src="/media/projects/manage/edit-project.png" />

  </Step>
  <Step title="Configure retention">

## Default project

Every workspace has a default project that cannot be deleted. Links created without an explicit project selection are assigned to the default project.
