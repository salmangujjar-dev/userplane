---
title: Intercom Shortcuts
description: Use Cmd+K in Intercom to quickly create recording links without leaving the conversation
---

When you [connect Intercom](/integrations/intercom), Userplane is added as an Intercom shortcut. Shortcuts let agents create recording links in seconds using the Cmd+K action menu, without navigating away from the current conversation.

## Opening the shortcut

<Steps>
  <Step title="Open the action menu">
    From a conversation in the Intercom inbox, press **Cmd+K** (Mac) or **Ctrl+K** (Windows) to open the action menu.
  </Step>
  <Step title="Find Userplane">
    Type **Userplane** to filter the list, then select **Use Userplane** and press **Enter**.

    <Frame caption="Userplane shortcut in Cmd+K menu">
      <img src="/media/intercom/intercom-inbox/shortcuts/intercom-userplane-shortcut.png" />
    </Frame>

  </Step>
  <Step title="Fill in the link details">
    Select a **project** and **domain** from the dropdowns. Optionally edit the **message to customer** that accompanies the recording card.

    <Frame caption="Create link form via shortcut">
      <img src="/media/intercom/intercom-inbox/shortcuts/intercom-create-link-form-shortcut.png" />
    </Frame>

  </Step>
  <Step title="Create and send">
    Click **Create Link**. A recording card is automatically inserted into the conversation. The customer sees a card they can click to start recording.

    <Frame caption="Recording link sent to customer">
      <img src="/media/intercom/intercom-inbox/intercom-recording-link-sent.png" />
    </Frame>

  </Step>
</Steps>

## After the link is created

- You will see a confirmation with a link to the recording.
- Click **Create another link** to start a new one, or **Done** to close.
- The recording is linked to the current Intercom conversation and appears in your Userplane dashboard.

<Frame caption="Link created confirmation">
  <img src="/media/intercom/intercom-inbox/sidebar/intercom-created-link-sidebar.png" />
</Frame>

## When to use shortcuts vs. the sidebar app

|              | Shortcut (Cmd+K)                         | Sidebar app                                     |
| ------------ | ---------------------------------------- | ----------------------------------------------- |
| **Access**   | Cmd+K from anywhere in a conversation    | Click Userplane in the conversation sidebar     |
| **Best for** | Quickly creating a single recording link | Browsing existing recordings and creating links |
| **Speed**    | Fastest — keyboard-driven, no navigation | Slightly more steps to open                     |

Both surfaces use the same project and domain options, and both create the same recording links. Choose whichever fits your workflow.

## Requirements

- The Intercom integration must be [connected](/integrations/intercom).
- The agent must be a member of the Userplane workspace.
