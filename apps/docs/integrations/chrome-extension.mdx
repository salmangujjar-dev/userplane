The Chrome extension lets your support team create recording links, manage links, and view recordings from a dedicated side panel — without leaving the browser tab. It works alongside any web-based tool, including help desks, CRMs, and internal dashboards.

## What the extension does

- Opens as a Chrome **side panel** for creating, managing, and sharing recording links.
- Supports a **keyboard shortcut** (`Cmd+Shift+Y` on Mac, `Ctrl+Shift+Y` on Windows/Linux) to open the Create Link form instantly.
- Provides **right-click context menus** for creating links and navigating to links or recordings.
- Includes an **omnibox command** — type `userplane` in the address bar, then a reference — to jump straight to link creation with a pre-filled reference.
- **Auto-populates** the link reference field with the current page URL (configurable in settings).
- Supports **workspace switching** for teams with multiple workspaces.

<Note>
  The Chrome extension is a management tool — it does not record the screen itself. Customers record
  by clicking the recording link you share with them.
</Note>

## Installing the extension

<Steps>
  <Step title="Install from the Chrome Web Store">
    Find **Userplane** in the [Chrome Web Store](https://chromewebstore.google.com/detail/request-screen-recording/bgmbeifpcfepegcjhjdbocjbecpfmakm) and click **Add to Chrome**.

  </Step>
  <Step title="Pin the extension">
    Click the **Extensions** icon (puzzle piece) in the Chrome toolbar and pin Userplane so it's always visible.

    <Frame caption="Pin the Userplane extension">
      <img src="/media/extension/extension-pin-chrome-extension.png" />
    </Frame>

  </Step>
  <Step title="Open the side panel">
    Click the **Userplane** icon in the toolbar. The side panel opens on the right side of your browser window.
  </Step>
</Steps>

## Signing in

<Steps>
  <Step title="Click Sign In">
    On first open, the side panel shows a login prompt. Click **Sign in to continue**.

    <Frame caption="Extension login prompt">
      <img src="/media/extension/extension-sign-in-continue.png" />
    </Frame>

  </Step>
  <Step title="Authenticate via the dashboard">
    A new tab opens to the Userplane dashboard. Sign in with your account.

    <Frame caption="Sign in via the Userplane dashboard">
      <img src="/media/extension/dash-pre-login.png" />
    </Frame>

  </Step>
  <Step title="Return to the side panel">
    Return to the side panel. If it hasn't updated, click **Already signed in? Refresh**.

    <Frame caption="Userplane dashboard after sign-in">
      <img src="/media/extension/dash-post-login.png" />
    </Frame>

  </Step>
  <Step title="Select your workspace">
    If you belong to multiple workspaces, select the one you want to use. You can switch workspaces later from the Settings tab.

    <Frame caption="Workspace selector">
      <img src="/media/extension/extension-setting-workspace-switcher.png" />
    </Frame>

  </Step>
</Steps>

## Extension permissions

When you install the extension, Chrome grants the following permissions:

| Permission        | What it's used for                                           |
| ----------------- | ------------------------------------------------------------ |
| **Storage**       | Persisting your workspace selection and preferences          |
| **Side Panel**    | Displaying the Userplane interface alongside your browser    |
| **Tabs**          | Reading the current tab URL to auto-populate link references |
| **Context Menus** | Adding right-click options for quick link creation           |

The extension also communicates with the Userplane API to fetch and manage your workspace data.

<Note>If you don't have a workspace yet, the extension prompts you to create one.</Note>

<Frame caption="No workspace yet — create one to get started">

</Frame>

## Requirements

- Google Chrome (or Chromium-based browsers like Edge)
- A Userplane workspace account
