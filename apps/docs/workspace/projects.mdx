Projects are a way to organize your recordings and links into logical groups. You might create a project for each product area, team, or customer segment.

## What projects are

A project is a named container within your workspace. Every recording link is assigned to a project, and the recording it produces inherits that assignment. This lets you filter, browse, and manage recordings by project.

<Frame caption="Project recordings">
  <img src="/media/projects/view/view-recordings.png" />
</Frame>

## Default project

Every workspace has a **default project** that is created automatically. The default project cannot be deleted. Recording links created without specifying a project are assigned to the default project.

## Creating a project

<Steps>
  <Step title="Open Projects settings">
    Go to [Workspace Settings > Projects](https://dash.userplane.io/_/settings?tab=general).

    <Frame caption="Projects list">
      <img src="/media/projects/projects-list.png" />
    </Frame>

  </Step>
  <Step title="Click Create Project">
    Click **Create Project** to open the creation dialog.

    <Frame caption="Projects list">
      <img src="/media/workspace/projects/view-projects.png" />
    </Frame>

  </Step>
  <Step title="Enter a name and save">
    Enter a name for the project and click **Save**.

    <Frame caption="Create project dialog">
      <img src="/media/projects/create-project-dialog.png" />
    </Frame>

  </Step>
</Steps>
