---
title: List Workspaces
description: Retrieve a paginated list of workspaces for the authenticated user
---

`GET /public/workspaces`

Returns a paginated list of workspaces the authenticated user belongs to.

## Query parameters

<ParamField query="page" type="integer" default="1">
  Page number (1-indexed)
</ParamField>
<ParamField query="per_page" type="integer" default="10">
  Items per page (min: 1, max: 20)
</ParamField>
<ParamField query="include_workspace_membership" type="boolean" default="false">
  Include the user's membership details (role, member ID) for each workspace
</ParamField>

## Response

<ResponseField name="message" type="string">
  Status message
</ResponseField>
<ResponseField name="data" type="object">
  <Expandable title="data">
    <ResponseField name="workspaces" type="array">
      <Expandable title="workspace item">
        <ResponseField name="workspaceId" type="string">
          Workspace ID
        </ResponseField>
        <ResponseField name="workspaceName" type="string">
          Workspace name
        </ResponseField>
        <ResponseField name="createdAt" type="string">
          ISO 8601 timestamp
        </ResponseField>
        <ResponseField name="updatedAt" type="string">
          ISO 8601 timestamp
        </ResponseField>
        <ResponseField name="workspaceMembership" type="object">
          Only included when `include_workspace_membership` is `true`
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="total" type="integer">
      Total number of workspaces
    </ResponseField>
    <ResponseField name="pagination" type="object">
      [Pagination metadata](/api/pagination#pagination-metadata)
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash curl
curl "https://api.userplane.com/api/v1/public/workspaces?page=1&per_page=10" \
  -H "Authorization: Bearer up_your_api_key"
```

```javascript JavaScript
const response = await fetch(
  'https://api.userplane.com/api/v1/public/workspaces?page=1&per_page=10',
  { headers: { Authorization: 'Bearer up_your_api_key' } }
);
const { data } = await response.json();
```

</CodeGroup>
