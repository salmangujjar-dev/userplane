---
title: Get Project
description: Retrieve project details by ID
---

`GET /public/workspace/{workspaceId}/projects/{projectId}`

Returns details for a specific project in the workspace.

## Path parameters

<ParamField path="workspaceId" type="string" required>
  The workspace ID
</ParamField>
<ParamField path="projectId" type="string" required>
  The project ID
</ParamField>

## Response

<ResponseField name="message" type="string">
  Status message
</ResponseField>
<ResponseField name="data" type="object">
  <Expandable title="data">
    <ResponseField name="workspaceId" type="string">
      Workspace ID
    </ResponseField>
    <ResponseField name="project" type="object">
      <Expandable title="project">
        <ResponseField name="projectId" type="string">
          Project ID
        </ResponseField>
        <ResponseField name="projectTitle" type="string">
          Project title
        </ResponseField>
        <ResponseField name="isDefault" type="boolean">
          Whether this is the default project
        </ResponseField>
        <ResponseField name="recordingRetentionDays" type="integer">
          Recording retention period in days
        </ResponseField>
        <ResponseField name="createdAt" type="string">
          ISO 8601 timestamp
        </ResponseField>
        <ResponseField name="updatedAt" type="string">
          ISO 8601 timestamp
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash curl
curl https://api.userplane.com/api/v1/public/workspace/ws_abc123/projects/proj_def456 \
  -H "Authorization: Bearer up_your_api_key"
```

```javascript JavaScript
const response = await fetch(
  'https://api.userplane.com/api/v1/public/workspace/ws_abc123/projects/proj_def456',
  { headers: { Authorization: 'Bearer up_your_api_key' } }
);
const { data } = await response.json();
```

</CodeGroup>

```json Response
{
  "message": "Project retrieved successfully",
  "data": {
    "workspaceId": "ws_abc123",
    "project": {
      "projectId": "proj_def456",
      "projectTitle": "Main App",
      "isDefault": true,
      "recordingRetentionDays": 30,
      "createdAt": "2025-01-10T08:00:00.000Z",
      "updatedAt": "2025-03-20T14:30:00.000Z"
    }
  }
}
```

## Errors

| Error code          | Status | Description              |
| ------------------- | ------ | ------------------------ |
| `PROJECT_NOT_FOUND` | 404    | Project does not exist   |
| `PROJECT_GONE`      | 410    | Project has been deleted |

Also returns [common authentication errors](/api/error-handling#authentication-errors).
