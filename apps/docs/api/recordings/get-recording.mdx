title: Get Recording
description: Retrieve complete recording details
---

`GET /public/workspace/{workspaceId}/recordings/{recordingId}`

Returns full details for a specific recording, including metadata about the link, creator, project, domain, and capture status.

## Path parameters

<ParamField path="workspaceId" type="string" required>
  The workspace ID
</ParamField>
<ParamField path="recordingId" type="string" required>
  The recording ID
</ParamField>

## Example

<CodeGroup>
```bash curl
curl https://api.userplane.com/api/v1/public/workspace/ws_abc123/recordings/rec_abc123 \
  -H "Authorization: Bearer up_your_api_key"
```

```javascript JavaScript
const response = await fetch(
  'https://api.userplane.com/api/v1/public/workspace/ws_abc123/recordings/rec_abc123',
  { headers: { Authorization: 'Bearer up_your_api_key' } }
);
const { data } = await response.json();
```

## Errors

| Error code            | Status | Description                        |
| --------------------- | ------ | ---------------------------------- |
| `RECORDING_NOT_FOUND` | 404    | Recording does not exist           |
| `RECORDING_GONE`      | 410    | Recording has already been deleted |

Also returns [common authentication errors](/api/error-handling#authentication-errors).
