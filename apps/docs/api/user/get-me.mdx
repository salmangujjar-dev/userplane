---
title: Get Current User
description: Retrieve the authenticated user's profile and aggregate stats
---

`GET /public/me`

Returns the profile and aggregate statistics for the user associated with the API key.

## Response

<ResponseField name="message" type="string">
  Status message
</ResponseField>
<ResponseField name="data" type="object">
  <Expandable title="data">
    <ResponseField name="user" type="object">
      <Expandable title="user">
        <ResponseField name="id" type="string">
          User ID
        </ResponseField>
        <ResponseField name="name" type="string">
          Display name
        </ResponseField>
        <ResponseField name="email" type="string">
          Email address
        </ResponseField>
        <ResponseField name="emailVerified" type="boolean">
          Whether the email has been verified
        </ResponseField>
        <ResponseField name="image" type="string | null">
          Profile image URL
        </ResponseField>
        <ResponseField name="createdAt" type="string">
          ISO 8601 timestamp
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="stats" type="object">
      <Expandable title="stats">
        <ResponseField name="workspaces" type="integer">
          Total workspaces the user belongs to
        </ResponseField>
        <ResponseField name="recordings" type="integer">
          Total recordings across all workspaces
        </ResponseField>
        <ResponseField name="links" type="integer">
          Total links across all workspaces
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash curl
curl https://api.userplane.com/api/v1/public/me \
  -H "Authorization: Bearer up_your_api_key"
```

```javascript JavaScript
const response = await fetch('https://api.userplane.com/api/v1/public/me', {
  headers: { Authorization: 'Bearer up_your_api_key' },
});
const { data } = await response.json();
```

</CodeGroup>

```json Response
{
  "message": "User profile retrieved successfully",
  "data": {
    "user": {
      "id": "user_abc123",
      "name": "Jane Doe",
      "email": "jane@example.com",
      "emailVerified": true,
      "image": null,
      "createdAt": "2025-01-15T10:30:00.000Z"
    },
    "stats": {
      "workspaces": 2,
      "recordings": 48,
      "links": 15
    }
  }
}
```

## Errors

This endpoint only returns [common authentication errors](/api/error-handling#authentication-errors).
