---
title: Update Link
description: Update recording link settings
---

`PUT /public/workspace/{workspaceId}/links/{linkId}`

Updates the settings of an existing recording link. All body fields are optional — only include the fields you want to change.

## Path parameters

<ParamField path="workspaceId" type="string" required>
  The workspace ID
</ParamField>
<ParamField path="linkId" type="string" required>
  The link ID
</ParamField>

## Request body

<ParamField body="linkTitle" type="string | null">
  Link title (max 255 characters). Set to `null` to clear.
</ParamField>
<ParamField body="linkReusable" type="boolean">
  Whether the link can be used for multiple recordings
</ParamField>
<ParamField body="linkProviderType" type="string">
  Integration provider type (e.g., `intercom`, `zendesk`, `slack`, `web`)
</ParamField>
<ParamField body="linkProviderId" type="string | null">
  Provider-specific ID (max 255 characters). Set to `null` to clear.
</ParamField>
<ParamField body="linkProviderRef" type="string | null">
  Provider-specific reference (max 2048 characters). Set to `null` to clear.
</ParamField>
<ParamField body="meta" type="object">
  Key-value metadata pairs. Keys must be alphanumeric, hyphens, or underscores.
</ParamField>

## Response

<ResponseField name="message" type="string">
  Status message
</ResponseField>
<ResponseField name="data" type="object">
  <Expandable title="data">
    <ResponseField name="workspaceId" type="string">
      Workspace ID
    </ResponseField>
    <ResponseField name="link" type="object">
      The updated link object. See [List Links](/api/links/list-links) for the full link item shape.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash curl
curl -X PUT https://api.userplane.com/api/v1/public/workspace/ws_abc123/links/link_xyz789 \
  -H "Authorization: Bearer up_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "linkTitle": "Updated Bug Report #142",
    "linkReusable": true
  }'
```

```javascript JavaScript
const response = await fetch(
  'https://api.userplane.com/api/v1/public/workspace/ws_abc123/links/link_xyz789',
  {

    },

const { data } = await response.json();
```

## Errors

| Error code           | Status | Description               |
| -------------------- | ------ | ------------------------- |
| `LINK_NOT_FOUND`     | 404    | Link does not exist       |
| `LINK_GONE`          | 410    | Link has been deleted     |
| `LINK_UPDATE_FAILED` | 500    | Failed to update the link |

Also returns [common authentication errors](/api/error-handling#authentication-errors).
