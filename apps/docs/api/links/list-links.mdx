title: List Links
description: Retrieve a paginated list of recording links with optional filters
---

`GET /public/workspace/{workspaceId}/links`

Returns a paginated list of recording links in the specified workspace with optional filtering and sorting.

## Path parameters

<ParamField path="workspaceId" type="string" required>
  The workspace ID
</ParamField>

## Query parameters

<ParamField query="page" type="integer" default="1">
  Page number (1-indexed)
</ParamField>
<ParamField query="per_page" type="integer" default="10">
  Items per page (min: 1, max: 20)
</ParamField>
<ParamField query="created_by" type="string[]">
  Filter by workspace member IDs who created the links
</ParamField>
<ParamField query="project_id" type="string[]">
  Filter by project IDs
</ParamField>
<ParamField query="domain_id" type="string[]">
  Filter by domain IDs
</ParamField>
<ParamField query="link_provider_type" type="string[]">
  Filter by link provider types. Values include: `intercom`, `zendesk`, `hubspot`, `freshdesk`,
  `freshchat`, `jira_service_management`, `helpscout`, `happyfox`, `ada`, `forethought`,
  `servicenow`, `front`, `zoho_desk`, `crisp`, `pylon`, `plain`, `asana`, `azure_devops`, `clickup`,
  `github`, `gitlab`, `jira`, `linear`, `notion`, `sentry`, `slack`, `web`, `others`
</ParamField>
<ParamField query="link_type" type="string">
  Filter by link type. One of: `file`, `recording`, `session`, `screenshot`
</ParamField>
<ParamField query="sort_by" type="string" default="created_at">
  Sort field. One of: `created_at`, `link_title`
</ParamField>
<ParamField query="sort_direction" type="string" default="desc">
  Sort direction. One of: `asc`, `desc`
</ParamField>

## Example

<CodeGroup>
```bash curl
curl "https://api.userplane.com/api/v1/public/workspace/ws_abc123/links?page=1&per_page=10&link_type=recording" \
  -H "Authorization: Bearer up_your_api_key"
```

```javascript JavaScript
const response = await fetch(
  'https://api.userplane.com/api/v1/public/workspace/ws_abc123/links?page=1&per_page=10&link_type=recording',
  { headers: { Authorization: 'Bearer up_your_api_key' } }
);
const { data } = await response.json();
```
