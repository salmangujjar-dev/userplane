---
title: Get Link
description: Retrieve recording link details by ID
---

`GET /public/workspace/{workspaceId}/links/{linkId}`

Returns details for a specific recording link.

## Path parameters

<ParamField path="workspaceId" type="string" required>
  The workspace ID
</ParamField>
<ParamField path="linkId" type="string" required>
  The link ID
</ParamField>

## Response

<ResponseField name="message" type="string">
  Status message
</ResponseField>
<ResponseField name="data" type="object">
  <Expandable title="data">
    <ResponseField name="workspaceId" type="string">
      Workspace ID
    </ResponseField>
    <ResponseField name="link" type="object">
      The link object. See [List Links](/api/links/list-links) for the full link item shape.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash curl
curl https://api.userplane.com/api/v1/public/workspace/ws_abc123/links/link_xyz789 \
  -H "Authorization: Bearer up_your_api_key"
```

```javascript JavaScript
const response = await fetch(
  'https://api.userplane.com/api/v1/public/workspace/ws_abc123/links/link_xyz789',
  { headers: { Authorization: 'Bearer up_your_api_key' } }
);
const { data } = await response.json();
```

## Errors

| Error code       | Status | Description           |
| ---------------- | ------ | --------------------- |
| `LINK_NOT_FOUND` | 404    | Link does not exist   |
| `LINK_GONE`      | 410    | Link has been deleted |

Also returns [common authentication errors](/api/error-handling#authentication-errors).
