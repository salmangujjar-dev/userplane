# Web SDK

The Userplane Web SDK allows you to record user sessions from any web application.

## Installation

```bash
npm install @userplane/sdk
```

## Usage

```javascript
import { Userplane } from '@userplane/sdk';

Userplane.init({
  projectId: 'your-project-id',
});
```
