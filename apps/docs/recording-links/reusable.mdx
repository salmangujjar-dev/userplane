---
title: Reusable Recording Links
description: Use reusable links in help docs, macros, and templates for repeat recording collection
---

A **reusable recording link** can be used multiple times — by multiple customers, a customer group, or even the same customer multiple times. Instead of creating a new link each time, you create one link and use it over and over. Each use creates a separate recording, all organized under that same link.

## When to use reusable links

Reusable links work best when you want to collect recordings from multiple customers using the same entry point:

- **Help center articles** — embed a reusable link in a troubleshooting guide so any customer reading that article can submit a recording.
- **Support macros** — create a macro in [Intercom](/integrations/intercom-macros) or share via your help desk with a reusable link that agents can send to customers without creating a new link each time.
- **Slack channels** — pin a reusable link in a Slack channel so any agent can share it when a customer needs to record.
- **Email templates** — add a reusable link to your canned responses or email signatures.
- **Support forms and feedback** — place a link in your app's support section, feedback forms, or help widgets for ongoing recording collection.

## Choosing between one-time and reusable

| Feature           | One-time                         | Reusable                     |
| ----------------- | -------------------------------- | ---------------------------- |
| Uses              | Single recording                 | Unlimited recordings         |
| Best for          | Individual support conversations | Templates, macros, help docs |
| Expires after use | Yes                              | No                           |

Use one-time links when you're working directly with a specific customer. Use reusable links when you want to collect recordings from many customers through the same channel.
