title: Managing Recording Links
description: Browse, filter, and manage your recording links from the Links page
---

The [Links](https://dash.userplane.io/_/links) page gives you a central view of all recording links in your workspace. From here you can create, share, edit, and delete links.

## List view

Links are displayed in a paginated list. Each link shows its reference, project, domain, creation date, and whether it is reusable or one-time.

## Sorting and pagination

Sort links by creation date or other fields to find what you need. Navigate between pages using the pagination controls at the bottom of the list.

## Link actions

Each link supports the following actions:

| Action     | Description                                                         |
| ---------- | ------------------------------------------------------------------- |
| **Share**  | Copy the link URL to your clipboard.                                |
| **View**   | Open the link detail page to see associated recordings.             |
| **Edit**   | Update the link's reference, project, or other details.             |
| **Delete** | Permanently remove the link. Associated recordings are not deleted. |
