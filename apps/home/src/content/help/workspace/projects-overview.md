Projects are a way to organize your recordings and links into logical groups. You might create a project for each product area, team, or customer segment.

## What projects are

A project is a named container within your workspace. Every recording link is assigned to a project, and the recording it produces inherits that assignment. This lets you filter, browse, and manage recordings by project.

## Default project

Every workspace has a **default project** that is created automatically. The default project cannot be deleted. Recording links created without specifying a project are assigned to the default project.

## Creating a project

1. Go to [Workspace Settings > Projects](https://dash.userplane.io/_/settings?tab=general).
2. Click **Create Project**.
3. Enter a name for the project.
4. Click **Save**.

## Using projects

- **When creating links** — select a project from the dropdown to assign the link.
- **When reviewing recordings** — filter by project on the Recordings page to see only relevant recordings.
- **When managing links** — filter by project on the Links page.
- **Project views** — switch to a project-scoped view for a focused look at a single project's recordings and links.
