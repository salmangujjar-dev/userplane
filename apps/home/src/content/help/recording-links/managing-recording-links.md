The **Links** page gives you a central view of all recording links in your workspace. From here you can create, share, edit, and delete links.

## List view

Links are displayed in a paginated list. Each link shows its reference, project, domain, creation date, and whether it is reusable or one-time.

## Filtering links

Use the filter controls to narrow the list:

- **Project** — show links from a specific project.
- **Member** — show links created by a specific team member.
- **Domain** — show links associated with a specific domain.

## Sorting

Sort links by creation date or other fields to find what you need.

## Pagination

Navigate between pages using the pagination controls at the bottom of the list.

## Link actions

Each link supports the following actions:

| Action     | Description                                                         |
| ---------- | ------------------------------------------------------------------- |
| **Share**  | Copy the link URL to your clipboard.                                |
| **View**   | Open the link detail page to see associated recordings.             |
| **Edit**   | Update the link's reference, project, or other details.             |
| **Delete** | Permanently remove the link. Associated recordings are not deleted. |

## Creating a new link

Click **Create Link** to open the creation form. See [Requesting a Recording](/help/recording/requesting-a-recording) for a walkthrough.
