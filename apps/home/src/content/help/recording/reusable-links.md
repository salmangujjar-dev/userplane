When you create a recording link, you choose whether it is **one-time** or **reusable**.

## One-time links

A one-time link can only be used for a single recording. After the customer completes a recording, the link expires. This is the default and works well for most support conversations where you need one recording per issue.

## Reusable links

A reusable link can be used multiple times by different customers. Each use creates a separate recording tied to the same link. Reusable links are useful when you want to:

- **Embed in help docs** — add a recording link to your knowledge base so any customer can submit a recording.
- **Use in macros** — create an [Intercom macro](/help/integrations/intercom-macros) or help desk template with a reusable link that agents can send repeatedly.
- **Collect ongoing feedback** — place a link in your app or onboarding flow to gather recordings over time.

## Creating a reusable link

1. Open the [Links](https://dash.userplane.io/_/links) page and click [Create Link](https://dash.userplane.io/_/recordings?create_link=true).
2. Toggle the **Reusable** option on.
3. Fill in the other details (project, domain, reference) and click **Create**.

## Viewing recordings from a reusable link

All recordings created from a reusable link appear in your Recordings page. You can filter by the link to see every recording associated with it.
