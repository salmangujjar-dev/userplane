When you create a recording link, you can select a verified domain to associate it with. This lets you create **first-party branded links** that look like they come from your own site rather than from a generic Userplane URL.

## Why domains matter

- **Trust** — customers are more likely to click a link that appears to come from your company.
- **Branding** — recording pages can display your company logo, colors, and messaging.
- **Per-domain settings** — each domain can have its own recording preferences (what data gets captured, whether sensitive fields are hidden).

## Selecting a domain when creating a link

1. When creating a recording link, use the **Domain** dropdown.
2. Only **verified** domains appear in the dropdown. Domains with a **pending** or **revoked** status are not available.
3. If you do not select a domain, the link uses default Userplane branding.

## Domain statuses

| Status       | Meaning                                                                                           |
| ------------ | ------------------------------------------------------------------------------------------------- |
| **Pending**  | Domain has been added but verification is not yet complete.                                       |
| **Verified** | Domain ownership is confirmed. You can create branded links and configure per-domain preferences. |
| **Revoked**  | Verification was revoked. The domain cannot be used for new links until re-verified.              |
