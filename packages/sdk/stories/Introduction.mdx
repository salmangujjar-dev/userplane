# Userplane SDK

The Userplane SDK (`@workspace/sdk`) embeds a screen recorder into any web application. It manages the full lifecycle of a recording session — from mounting an isolated iframe to coordinating cross-tab state — without polluting the host page.

## What the SDK Does

```
┌─────────────────────────────────────────────────────────────┐
│                        Host Page                             │
│                                                             │
│   import { initialize } from '@workspace/sdk'               │
│   initialize({ workspaceId: 'ws_...' })                      │
│           │                                                 │
│           ▼                                                 │
│   ┌───────────────┐    PostBridge RPC    ┌───────────────┐  │
│   │  SDK (host)   │◄──────────────────►│ Recorder iframe│  │
│   │               │                    │  (guest)       │  │
│   │ • session mgmt│                    │ • capture video │  │
│   │ • metadata    │                    │ • record audio  │  │
│   │ • tab identity│                    │ • send to cloud │  │
│   └───────────────┘                    └───────────────┘  │
│           │                                     │          │
│           └──────────── Userplane Cloud ─────────┘         │
└─────────────────────────────────────────────────────────────┘
```

The SDK acts as the **host** in a PostBridge RPC pair. The recorder runs in a sandboxed iframe as the **guest**. They communicate via structured RPC — the host never has direct DOM access to the recorder, and vice versa.

## Key Features

| Feature | Description |
|---------|-------------|
| **SSR-safe** | No `window`/`document` access on import — safe to import in Next.js, Nuxt, SvelteKit |
| **Tree-shakeable** | `"sideEffects": false` — unused exports are dropped by bundlers |
| **Zero import side effects** | Nothing executes until you call `initialize()` |
| **TypeScript** | Full type definitions exported — no `@types/` package needed |
| **Cross-tab coordination** | Hidden capture iframe tracks recorder state across tabs |
| **Privacy blur** | Integrates with `@workspace/blurr` for sensitive field masking |
| **Metadata** | Static and dynamic key-value pairs attached to each recording |

## Simplest Possible Setup

```html
<!-- 1. Add your workspace ID to the page -->
<meta name="userplane:workspace" content="ws_your_workspace_id" />
```

```typescript
// 2. Initialize the SDK once (e.g., in your app entry point)
import { initialize } from '@workspace/sdk';

initialize();
// That's it — the SDK will open the recorder when a
// userplane-token URL parameter is detected.
```
