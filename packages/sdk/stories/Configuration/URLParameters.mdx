# URL Parameters

The SDK communicates with the Userplane platform through URL query parameters. Understanding these helps you debug, build custom integrations, and control the SDK's behavior.

## Recognized Parameters

| Parameter             | Purpose                                                      |
| --------------------- | ------------------------------------------------------------ |
| `userplane-token`     | Authentication token for the action                          |
| `userplane-action`    | Which action to perform                                      |
| `userplane-workspace` | Workspace ID override (appended by the SDK to recorder URLs) |
| `userplane-meta`      | Forwarded metadata (read by the recorder)                    |

## `userplane-token`

The authentication token for a recording or verification session. Generated by the Userplane backend and embedded in sharing links.

```
https://yourapp.com/page?userplane-token=tok_abc123def456
```

The SDK reads this on `initialize()` (when `openImmediately` is `true`) and uses it to build the recorder URL.

## `userplane-action`

Determines which type of iframe the SDK mounts:

| Value       | Behavior                                                  |
| ----------- | --------------------------------------------------------- |
| `recording` | Mounts the recorder iframe — full screen recording UI     |
| `verify`    | Mounts the verification iframe — domain verification flow |
| `capture`   | Mounts the capture iframe — cross-tab metadata capture    |

```
https://yourapp.com/?userplane-token=tok_abc&userplane-action=recording
```

If `userplane-action` is absent, the SDK defaults to `recording`.

## `userplane-meta`

An optional base64-encoded JSON string of metadata to forward to the recorder. The SDK reads this from the URL and passes it through the bridge.

## How the SDK Reads URL Parameters

On `initialize()` (with `openImmediately: true`), the SDK:

1. Reads `window.location.href`
2. Extracts `userplane-token` and `userplane-action`
3. Validates the action (must be `recording`, `verify`, or `capture`)
4. If valid, opens the appropriate frame manager

```typescript
// Default parsing logic (simplified)
const url = new URL(window.location.href);
const token = url.searchParams.get('userplane-token');
const action = url.searchParams.get('userplane-action') ?? 'recording';
```

## URL Cleanup

After the SDK reads the parameters, it **removes them from the URL** without reloading the page:

```typescript
// Parameters are cleaned up automatically
// Before: https://yourapp.com/page?userplane-token=tok_abc&userplane-action=recording&other=value
// After:  https://yourapp.com/page?other=value
```

This uses `history.replaceState` — the page doesn't reload, the URL is simply updated in the address bar and `window.location`.

## Custom URL Parsing

Override the parsing and cleanup with `parseUserplaneData` and `applyUserplaneData` in `InitializeOptions`:

```typescript
initialize({
  // Custom parser — e.g., if your app uses hash-based routing
  parseUserplaneData: (href) => {
    const hash = new URL(href).hash.slice(1);
    const params = new URLSearchParams(hash);
    const token = params.get('up-token');
    const action = params.get('up-action');
    if (!token) return null;
    return { token, action: (action as ActionType) ?? 'recording' };
  },

  // Custom cleanup — remove from hash instead of query string
  applyUserplaneData: (_data) => {
    const url = new URL(window.location.href);
    const hash = new URLSearchParams(url.hash.slice(1));
    hash.delete('up-token');
    hash.delete('up-action');
    url.hash = hash.toString();
    return url.toString();
  },
});
```

## Building a Recording URL

The SDK constructs recorder URLs in this format:

```
{recorderBaseUrl}/r
  ?userplane-token={token}
  &userplane-action=recording
  &userplane-workspace={workspaceId1,workspaceId2}
```

Example:

```
https://recorder.userplane.io/r
  ?userplane-token=tok_abc123
  &userplane-action=recording
  &userplane-workspace=ws_aaa
```

This URL is set as the `src` of the recorder iframe.
