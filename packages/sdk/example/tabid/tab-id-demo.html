Technical Details

The Tab Ref is generated using nanoid for cryptographically strong random IDs. Format: tab_[nanoid]

It's stored in three places:

  • sessionStorage.getItem('userplane_tab_ref') - Persists for tab lifetime
  • window.__userplaneTabRef - In-memory global namespace
  • Userplane.getTabRef() - Instance method

Persistence: The Tab Ref survives page refreshes because it's stored in sessionStorage. Each browser tab has its own sessionStorage, so different tabs have different Tab Refs. The Tab Ref is cleared when the tab is closed.
