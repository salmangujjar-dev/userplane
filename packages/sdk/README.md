# Userplane Recorder SDK

Auto-mounts recorder iframe when users visit recording links. Drop in the script tag and it just works.

Based on [Jam's recording links pattern](https://jam.dev/docs/jam-for-customer-support/send-recording-links-from-your-own-domain-and-collect-console-logs).

## Features

- Auto-initialization on script load
- Workspace ID from meta tag
- URL parameter detection
- Automatic iframe mounting
- Zero configuration needed
- TypeScript definitions included
- Tiny bundle size (~3.6 KB gzipped)

## Quick Start

Add these two tags to your HTML `<head>`:

```html
<html>
  <head>
    <!-- Your workspace ID -->
    <meta name="userplane:workspace" content="ws_1uOpD71P19LJ" />

    <!-- Userplane recorder script -->
    <script type="module" src="https://cdn.userplane.com/recorder.js"></script>
  </head>
</html>
```

That's it! When users visit recording links like:

```
https://yoursite.com?userplane-action=recording&userplane-token=abc123
```

The recorder will automatically mount.

## How It Works

1. User clicks recording link (generated by your backend)
2. Script detects `userplane-action=recording` in URL
3. Reads `userplane-token` parameter
4. Reads workspace ID from meta tag
5. Mounts fullscreen recorder iframe with all parameters
6. Recorder validates workspace ID matches token payload
7. User records and submits

## Security

The workspace ID from the meta tag is passed to the recorder and validated against the `wid` field in the session token payload. This prevents recording links from one workspace being used on another workspace's site.

## Programmatic Access

The recorder is available at `window.Userplane.recorder`:

```javascript
// Check if mounted
if (window.Userplane.recorder.isRecorderMounted()) {
  console.log('Recorder is active');
}

// Unmount programmatically
window.Userplane.recorder.unmount();
```

## Meta Tag

The workspace ID meta tag is required:

```html
<meta name="userplane:workspace" content="ws_YOUR_WORKSPACE_ID" />
```

Get your workspace ID from your [Userplane dashboard](https://dash.userplane.com).

## URL Parameters

Recording links must include both parameters:

- `userplane-action=recording` - Triggers recorder mount
- `userplane-token=xxx` - Authentication token for the recording session

The token should be generated server-side for each recording request.

## Iframe Configuration

When mounted, the recorder iframe:

- Uses fullscreen overlay (position: fixed, inset: 0)
- Maximum z-index (2147483647)
- Backdrop blur for focus
- Sandbox: `allow-same-origin allow-scripts allow-popups`
- Permissions: `microphone; camera; display-capture`
- URL includes: `userplane-token`, `userplane-action`, `userplane-workspace`

### Workspace Validation

The recorder validates that the `userplane-workspace` parameter matches the `wid` (workspace ID) in the session token JWT payload. If they don't match, the recorder will show an error:

```
"Workspace mismatch: This recording link is not valid for this workspace"
```

This prevents someone from using a recording link generated for workspace A on workspace B's website.
