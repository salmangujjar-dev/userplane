# @userplane/embed

Auto-initializing embed script for CDN/script tag usage. The recorder iframe auto-mounts when users visit recording links.

## Package Overview

| Package               | Use Case                            |
| --------------------- | ----------------------------------- |
| `@userplane/embed`    | CDN/script tag (auto-initializes)   |
| `@userplane/sdk`      | NPM install (SSR-safe, manual init) |
| `@userplane/metadata` | Standalone metadata-only            |

## Quick Start

Add these two tags to your HTML `<head>`:

```html
<html>
  <head>
    <!-- Your workspace ID -->
    <meta name="userplane:workspace" content="ws_xxx" />

    <!-- Userplane embed script -->
    <script type="module" src="https://cdn.userplane.io/embed.js"></script>
  </head>
</html>
```

When users visit recording links:

```
https://yoursite.com?userplane-action=recording&userplane-token=abc123
```

The recorder automatically mounts.

## How It Works

1. User clicks recording link (generated by your backend)
2. Script detects `userplane-action=recording` in URL
3. Reads `userplane-token` parameter
4. Reads workspace ID from meta tag
5. Mounts fullscreen recorder iframe
6. Recorder validates workspace ID matches token payload
7. User records and submits

## API

The embed script exposes `window.userplane` with these methods:

```javascript
// Check state
userplane.isInitialized()
userplane.isRecorderMounted()
userplane.isBridgeConnected()

// Control recorder
userplane.open(token?)     // Open with optional token
userplane.unmount()        // Close recorder

// Get recording info
userplane.getRecordingState()   // 'inactive' | 'active' | 'retained'
userplane.getRecordingContext()
userplane.getSessionId()
userplane.getLinkId()
userplane.getTabRef()

// Metadata
userplane.metadata(() => ({ userId: '123', plan: 'pro' }))
userplane.clearMetadata()
```

## Manual Control

For advanced use cases, control when the recorder opens:

```html
<script type="module">
  import * as userplane from 'https://cdn.userplane.io/embed.js';

  // Initialize with manual control
  userplane.initialize({ openImmediately: false });

  // Open when ready (uses token from URL)
  document.getElementById('start-btn').addEventListener('click', () => {
    userplane.open();
  });

  // Or open with a custom token
  userplane.open('custom_token_123');

  // Close when done
  userplane.unmount();
</script>
```

## Initialize Options

```typescript
userplane.initialize({
  // Workspace ID (defaults to reading from meta tag)
  workspaceId: 'ws_xxx',

  // Auto-open behavior:
  // - true (default): Auto-open when URL params detected
  // - false: Don't auto-open, wait for manual open()
  // - string: Token to open immediately
  openImmediately: true,

  // Custom recorder URL
  recorderBaseUrl: 'https://recorder.userplane.io',

  // Custom URL parser (optional)
  parseUserplaneData: (href) => ({
    token: '...',
    action: 'recording',
  }),
});
```

## Metadata

Attach custom context to recordings:

```javascript
userplane.metadata(() => ({
  user: {
    id: getCurrentUser().id,
    email: getCurrentUser().email,
    plan: 'enterprise',
  },
  app: {
    version: '2.4.1',
    environment: 'production',
  },
  session: {
    id: getSessionId(),
    route: window.location.pathname,
  },
}));
```

The function is called when a recording is submitted, so it captures the current state.

## Tab Reference

Each browser tab gets a unique reference:

```javascript
const tabRef = userplane.getTabRef();
// => "tab_V1StGXR8_Z5jdHi6B"

// Also available at:
window.__userplaneTabRef;
sessionStorage.getItem('userplane_tab_ref');
```

The tab ref persists across page refreshes but is unique per tab.

## URL Parameters

Recording links must include:

- `userplane-action=recording` - Triggers recorder mount
- `userplane-token=xxx` - Authentication token

## Meta Tag

The workspace ID meta tag is required:

```html
<meta name="userplane:workspace" content="ws_YOUR_WORKSPACE_ID" />
```

Multiple workspace IDs can be specified for multi-tenant apps.
