# Build System Overview

The embed package has a dual-mode build: the same TypeScript source produces either a CDN-optimized bundle (two files for the two-stage loader) or a standard npm package (ESM + CJS + types).

## Output Files

### CDN Build (`bun run build:cdn`)

```
dist/
├── script.js        # Bootstrap loader (~1KB, stable URL)
└── main.js          # Full SDK bundle (no hash yet — hash added by upload script)
```

The hash is added during the R2 upload step, not during the build. This keeps the build deterministic and separates build from deploy.

### NPM Build (`bun run build`)

```
dist/
├── index.es.js      # ES module build
├── index.cjs.js     # CommonJS build
└── index.d.ts       # TypeScript declarations
```

## Build Commands

| Command | Mode | Description |
|---------|------|-------------|
| `bun run build` | NPM | Compile TS + Vite bundle for npm distribution |
| `bun run build:cdn` | CDN | Compile TS + Vite bundle with `OPTIMIZE_MODE=cdn` |
| `bun run deploy:cdn` | CDN | Build CDN output + upload to R2 in one step |
| `bun run upload:cdn` | — | Upload existing CDN build to R2 (no rebuild) |

## The OPTIMIZE_MODE Environment Variable

The `OPTIMIZE_MODE` env var controls which build profile Vite uses:

```bash
# NPM build (default)
bun run build
# → OPTIMIZE_MODE is unset → standard build

# CDN build
bun run build:cdn
# → OPTIMIZE_MODE=cdn → dual entry points, ES-only, minified
```

Inside `vite.config.ts`, the build config branches based on `process.env.OPTIMIZE_MODE`:

```typescript
const isCDN = process.env.OPTIMIZE_MODE === 'cdn';

export default defineConfig({
  build: isCDN ? cdnBuildConfig : npmBuildConfig,
  define: {
    __CDN_BASE_URL__: isCDN
      ? JSON.stringify(`https://${CDN_DOMAIN}/${R2_CDN_PREFIX}`)
      : JSON.stringify(''),
    __DEV__: isCDN ? 'false' : 'true',
  },
});
```

## CDN_DOMAIN and R2_CDN_PREFIX

The CDN base URL is baked into the bootstrap at build time. It is constructed from two environment variables:

| Variable | Example | Description |
|----------|---------|-------------|
| `CDN_DOMAIN` | `cdn.example.com` | Your CDN domain (no protocol) |
| `R2_CDN_PREFIX` | `embed` | Path prefix in the R2 bucket |

Result: `__CDN_BASE_URL__ = "https://cdn.example.com/embed"`

These are read from `.env.{environment}` files. See **[Deployment → Environment Setup](../?path=/docs/deployment-environment-setup--docs)** for details.

## Makefile Shortcuts

```bash
make embed:build             # NPM build
make embed:build:cdn         # CDN build (dev env)
make embed:build:cdn:production # CDN build (production env)
```
