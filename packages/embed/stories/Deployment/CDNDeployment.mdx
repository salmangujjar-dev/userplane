# CDN Deployment

The embed package ships with `scripts/upload-cdn.ts` — a Bun script that builds (optionally), hashes, and uploads the CDN files to a Cloudflare R2 bucket.

## Upload Commands

```bash
# Build + upload in one step (most common)
bun run deploy:cdn --env=production

# Upload only (assumes dist/ already built)
bun run upload:cdn --env=production

# Preview what would be uploaded without uploading
bun run upload:cdn --env=production --dry-run

# Force re-upload even if files haven't changed
bun run upload:cdn --env=production --force

# Upload only the manifest (e.g., to roll back a bad deploy)
bun run upload:cdn --env=production --manifest-only

# Verbose output
bun run upload:cdn --env=production --verbose
```

## What Gets Uploaded

Three objects are uploaded to R2 on every deploy:

| R2 Key | Source | Content-Type | Cache-Control |
|--------|--------|--------------|---------------|
| `{prefix}/script.js` | `dist/script.js` | `application/javascript` | `public, max-age=300` |
| `{prefix}/manifest.json` | Generated by upload script | `application/json` | `public, max-age=300` |
| `{prefix}/main.{hash}.js` | `dist/main.js` (renamed) | `application/javascript` | `public, max-age=31536000, immutable` |

Where `{prefix}` is the `R2_CDN_PREFIX` environment variable (e.g., `embed`).

## Deployment Workflow

```
bun run deploy:cdn --env=production
        │
        ▼
1. Load .env.production
        │
        ▼
2. bun run build:cdn
   └── tsc + OPTIMIZE_MODE=cdn vite build
   └── Produces: dist/script.js, dist/main.js
        │
        ▼
3. Compute content hash
   └── SHA-256(dist/main.js).slice(0, 16)
   └── hashedName = "main.{hash}.js"
        │
        ▼
4. Generate manifest.json
   └── { main: "main.{hash}.js", version, timestamp, contentHash }
        │
        ▼
5. Upload to R2
   ├── PUT {prefix}/script.js        (max-age=300)
   ├── PUT {prefix}/manifest.json    (max-age=300)
   └── PUT {prefix}/main.{hash}.js   (immutable)
        │
        ▼
6. Print output
   ├── CDN URLs for each file
   └── Embed snippet to paste into HTML
```

## Terminal Output

After a successful deploy, the script prints the embed snippet:

```
✓ Deployed to production CDN

Files uploaded:
  https://cdn.example.com/embed/script.js
  https://cdn.example.com/embed/manifest.json
  https://cdn.example.com/embed/main.a1b2c3d4e5f67890.js

Embed snippet:
  <meta name="userplane:workspace" content="ws_your_id" />
  <script src="https://cdn.example.com/embed/script.js" defer></script>
```

## Makefile Shortcuts

```bash
# Build CDN (dev environment)
make embed:build:cdn

# Build CDN (production environment)
make embed:build:cdn:production

# Upload to R2 (dev environment)
make embed:upload

# Upload to R2 (production environment)
make embed:upload:production

# Dry-run upload (preview only)
make embed:upload:dry-run

# Build + upload (dev environment)
make embed:deploy

# Build + upload (production environment)
make embed:deploy:production
```

## R2 Endpoint

The upload script constructs the R2 endpoint from your account ID:

```
https://{R2_CDN_ACCOUNT_ID}.r2.cloudflarestorage.com
```

The bucket name is `R2_CDN_BUCKET_NAME`.

See **[Environment Setup](../?path=/docs/deployment-environment-setup--docs)** for all required environment variables.
